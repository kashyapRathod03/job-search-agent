IMPORTANT BROWSER RULE
==================================================

LinkedIn element references such as:

@e14
@e26
@e55

are TEMPORARY.

NEVER assume that a ref remains valid after navigation, clicking,
filter changes, page changes, or dynamic UI updates.

After any significant UI change:

    agent-browser snapshot -i

Then inspect the NEW refs.

Never blindly reuse an old ref.

Example:

agent-browser snapshot -i

If the snapshot contains:

textbox "Search" [ref=e14]

then:

agent-browser fill @e14 "Java Developer"

After navigation:

agent-browser snapshot -i

The Search ref may now be different.

Use the new ref.
