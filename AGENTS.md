# Job Search Agent

## Purpose

This project is a personal job-search assistant.

The system searches job listings, extracts job information,
compares jobs against the user's verified profile and resume,
scores jobs, ranks them, and generates results.


## Browser

Use agent-browser for browser interaction.

## AI

Use ChatGPT 5 for reasoning and job matching.

## User Information

resume.md, profile.md, and preferences.md are sources of truth.

Never invent skills, experience, education, certifications,
companies, achievements, or technologies.

If information is unknown, mark it as unknown.
